Al entrar en un campo entero, decimal, monetario, de porcentaje o de
horas dentro de un formulario o una lista editable, se selecciona todo
su valor. Lo que el usuario escriba reemplaza el valor anterior en lugar
de sumarse a él.

Funciona tanto con el teclado (Tab) como con un clic del ratón. Cada
usuario puede activarlo o desactivarlo desde sus preferencias.

Use Cases / Context
===================

Odoo selecciona el valor de un campo numérico cuando se entra con Tab,
pero al hacer clic el navegador deshace esa selección y deja el cursor
donde se hizo clic. El usuario termina escribiendo ``1,0050`` en vez de
``50,00`` y tiene que borrar a mano.

En la captura de cantidades y precios conviene que el valor quede
seleccionado siempre, para escribir el nuevo número directamente. No
todos los usuarios lo prefieren, por eso la opción es por usuario.

Configuration
=============

1. Abra **Preferencias** desde el menú del usuario.
2. En **Campos numéricos**, marque o desmarque **Seleccionar números al
   enfocar**.
3. Guarde. El cliente web se recarga con la nueva preferencia.

Un administrador puede cambiar la opción de otro usuario desde **Ajustes
> Usuarios y compañías > Usuarios**, en la pestaña **Preferencias**. La
opción viene activada para todos al instalar.

Usage
=====

1. Abra un formulario o una lista editable con campos numéricos, por
   ejemplo una orden de venta.
2. Haga clic o entre con Tab en un campo como **Cantidad** o **Precio
   unitario**.
3. El valor completo queda seleccionado.
4. Escriba el número nuevo: reemplaza al anterior.
5. Para editar solo una parte, haga un segundo clic en la posición
   deseada.

Known issues / Roadmap
======================

- No es compatible con ``web_float_cursor_before_decimal``, que coloca
  el cursor antes del separador decimal al enfocar. Si ambos están
  instalados, el usuario debe desactivar esta opción para conservar el
  comportamiento del otro módulo.
- Cambiar la preferencia requiere recargar el cliente web.
