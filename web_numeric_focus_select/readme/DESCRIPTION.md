Al entrar en un campo entero, decimal, monetario, de porcentaje o de
horas dentro de un formulario o una lista editable, se selecciona todo su
valor. Lo que el usuario escriba reemplaza el valor anterior en lugar de
sumarse a él.

Funciona tanto con el teclado (Tab) como con un clic del ratón. Cada
usuario puede activarlo o desactivarlo desde sus preferencias.
