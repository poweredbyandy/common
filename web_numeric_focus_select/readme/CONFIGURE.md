1. Abra **Preferencias** desde el menú del usuario.
2. En **Campos numéricos**, marque o desmarque **Seleccionar números al
   enfocar**.
3. Guarde. El cliente web se recarga con la nueva preferencia.

Un administrador puede cambiar la opción de otro usuario desde
**Ajustes > Usuarios y compañías > Usuarios**, en la pestaña
**Preferencias**. La opción viene activada para todos al instalar.
