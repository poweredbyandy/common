1. Install the module (`pos_hr` is required).
2. Open the POS and log in as an employee.
3. Create a new order: the current employee is stored as **Seller**.
4. If another cashier later pays the order, **Cashier** may change but
   **Seller** remains the creator.
5. Review Seller in:
   - POS orders list (column next to Cashier)
   - Backend POS order form and list
   - Receipt header
6. Group or search orders by Seller in the backend orders search view.
