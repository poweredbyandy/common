1. Install the module (`pba_internal_code` and `website_sale` are required).
2. Go to Settings > Users & Companies > Users.
3. Create or open the user who should manage product photos.
4. Enable **only** Internal User plus **PBA: Configurador de productos**.
   Do not enable Sales, Purchase, Inventory or Contacts manager groups.
5. Log in with that user: only **Product Configurator > Products** appears.
6. Open a product: name, reference and internal code are read-only.
7. Update the main photo and/or website photos, then save.
