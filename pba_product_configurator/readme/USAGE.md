1. Install the module (`pba_internal_code` and `website_sale` are required).
2. Go to Settings > Users & Companies > Users.
3. Open the user who should manage product photos.
4. Enable the group **PBA: Configurador de productos**.
5. Log in with that user and open **Product Configurator > Products**.
6. Open a product: name, reference and internal code are read-only.
7. Update the main photo and/or website photos, then save.
