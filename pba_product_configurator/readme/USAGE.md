1. Install the module.
2. Go to Settings > Users & Companies > Users.
3. Open the user who should configure products.
4. Enable the group **PBA: Configurador de productos**.
5. Log in with that user: the **Product Configurator** app shows Products,
   Categories, Tags and (if variants are enabled) Variants and Attributes.
6. The user can create and edit products, but archiving or deleting them raises
   an access error.
7. Do not assign Sales or Purchase groups to this user if they must not sell or
   buy.
