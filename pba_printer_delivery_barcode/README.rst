===================================
PBA POS-80 Delivery Printer Barcode
===================================

Adds **Print POS-80** to the barcode picking screen.

Description
===========

The ticket and Device Bridge connection stay in ``pba_printer_delivery``.
This module only exposes the same action in the barcode app.

Use Cases / Context
===================

Operators who validate deliveries from the barcode app need the same POS-80
ticket without leaving that screen.

Usage
=====

#. Open a picking in Inventory / Barcode.
#. Open the print menu and choose **Print POS-80**.
#. The ticket is sent through Device Bridge like the picking form button.
