#. Instale el módulo *Colores del estado de entrega en compras*.
#. Vaya a **Compras > Pedidos > Órdenes de compra**.
#. Muestre la columna **Estado de entrega** si no está visible
   (menú de columnas opcionales).
#. El badge usa un color distinto por estado:

   * Azul si está **Sin recibir**.
   * Naranja si está **Recibido parcialmente**.
   * Verde si está **Recibido totalmente**.
