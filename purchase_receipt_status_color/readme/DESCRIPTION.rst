En el listado de órdenes de compra, Odoo colorea el badge de estado de
entrega según si la recepción va a tiempo o con retraso. Por eso
**Sin recibir** y **Recibido totalmente** pueden verse ambos en rojo.

Este módulo cambia esa lógica: el color depende del estado de recepción.

* Azul: Sin recibir
* Naranja: Recibido parcialmente
* Verde: Recibido totalmente
