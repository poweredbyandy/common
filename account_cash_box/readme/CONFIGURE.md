1. Go to **Accounting > Configuration > Journals** and open the cash journal.
   Set the default cash account, the profit account and the loss account.
2. Assign the **Cash Box / Cashier** or **Cash Box / Administrator** group
   to the users who will operate the drawer.
3. Go to **Cash Box > Cash Boxes** and create a cash box linked to that
   journal. Leave cashiers empty to allow every cash box user, or restrict
   the box to selected users.
4. Go to **Cash Box > Reasons** and create cash in / cash out reasons. Each
   reason must have a counterpart account (income, expense or transfer).
