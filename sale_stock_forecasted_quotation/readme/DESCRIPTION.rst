Este módulo cambia el reporte de inventario pronosticado para que los presupuestos en borrador o enviados no se agrupen en una sola fila.

En lugar de mostrar la cantidad total y una lista de pedidos (``2 | S0001, S0002``), cada presupuesto aparece en su propia línea con su cantidad y el nombre del contacto (``1 | S0001 - Cliente``).
