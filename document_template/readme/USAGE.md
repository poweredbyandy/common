1. Open **Document Templates** and create a template.
2. Choose the model (for example Contact or Sales Order).
3. Write the body, or import content:
   - **File → Import Markdown…** converts a `.md` file to rich text
     (headings, bold, lists, tables, etc.).
   - **File → Import Word / Google Docs…** imports a `.docx` export
     (from Google Docs: File → Download → Microsoft Word). Tables keep
     borders, header shading (navy bands), columns and checkboxes so the
     form looks like the source document.
   Use the formatting toolbar (font, size, bold, color, alignment) like
   in Google Docs. Use `/` or **Insert → Field** to insert Odoo values.
4. Click **Preview** to render the template against a sample record.
5. Click **Add to Print menu**.
6. Open a record of that model and use **Print** to download the filled
   PDF.
