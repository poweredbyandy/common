=============
Stade Dashboard
=============

Home dashboard for the Odoo backend based on web_responsive.

Features
--------

* Fullscreen apps home menu
* Upcoming activities below the apps
* Responsive UX improvements from web_responsive

Installation
------------

Install ``stade_dashboard``. It is incompatible with ``web_responsive`` and ``web_enterprise``.

Usage
-----

Enable **Redirect to Home** on the user (default when no home action is set).
Upcoming activities are listed below the apps grid on the home menu.
