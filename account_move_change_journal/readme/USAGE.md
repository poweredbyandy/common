1. Go to **Accounting > Customers > Invoices** or **Accounting > Vendors > Bills**.
2. Select one or more posted invoices of the same type and company.
3. Open **Action > Change Journal**.
4. Select the new journal and click **Change Journal**.

Only users in the **Accounting / Administrator** group see the action.

The invoice takes the next number of the new journal and the previous number
is left as a gap in the old journal. The chatter keeps the previous journal and
number.

The change is refused when the invoice is not posted, is protected by a hash,
is in a locked period, or when the new journal only accepts another currency.
