Cuando se factura y se entrega un pedido y luego se emite una nota de crédito,
el stock sigue en el cliente y, al devolverlo, la cantidad pedida del pedido
sigue siendo mayor que la entregada. Eso deja el pedido pendiente de un nuevo
envío. Este módulo cierra ese hueco: la nota de crédito dispara la devolución
y, al confirmarla, el pedido deja de pedir mercancía.
