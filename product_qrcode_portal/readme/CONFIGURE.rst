#. Install Website, eCommerce, Product QR Code, and this module.
#. Open Settings and open the Website section.
#. In Product QR URL, choose what happens when a visitor scans
   /product-qr?code=...&company_id=...
#. Each website uses its own domain and company in the portal QR URL.
#. When printing ZPL portal labels, pick the website (defaults to the current one).
#. Publish the products that should be reachable from that QR.
