1. Install the module (`point_of_sale` is required).
2. Enable **Allow Ship Later** on the POS configuration.
3. Enable **Ship Later by Default** (appears right after that setting).
4. Open a POS session and create an order: Ship Later is active with today's
   date.
5. On the payment screen, next to the Invoice / journal button, use the delivery
   address button:
   - **Local** (default): pickup in store, no delivery address required.
   - Or select the customer / one of its delivery addresses.
6. Click **Ship Later** to open the date picker and change the delivery date.
