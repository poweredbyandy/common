1. Install the module and open a POS session.
2. Hold **Shift** (outside the product search field).
3. Letter badges appear on the available actions.
4. Press the letter to run the action, still holding Shift if needed.
5. Release **Shift** to hide the badges.

Default letters:

* **B** — focus product search
* **P** — orders list (Pedidos)
* **N** — new order
* **C** — customer
* **G** — payment / Pay
* **S** — save order for later
* **A** — Actions
* **O** — quotations (when `pba_pos_sale` is installed)
* **K** — cart pane (mobile)
