This module adds a public website page where visitors can scan a product
barcode or QR with the camera, review prices and internal notes, and add the
item to the same cart used by the eCommerce shop.

Each product shows a product QR. If Product QR Code Portal is also installed,
it adds a portal QR. Configure that module to open Scan and Order when the
portal QR is scanned.

The page shows a loader first and loads the cart after the first paint so the
portal opens with as little work as possible.

Visitors do not need to create an account. The page uses the website public
user and the standard website sale order. Buy saves the quotation and shows
the order number. The visitor can leave their RIF, name, phone and email, or
register that data at the cashier, then go pay. They can also remove every
item from the cart.

Prices are shown in the company currency and in the configured pricelist
currency, both with and without taxes.
