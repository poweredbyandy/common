#. Install Website, eCommerce, Product QR Code, Product QR Code Portal,
   and this module.
#. Open Settings and open the Website section.
#. In Product QR URL, choose what happens when a visitor scans
   /product-qr?code=...
#. Choose the Scan and Order Pricelist. Leave it empty to use the website
   pricelist.
#. Choose the Button Color and Button Text Color used on /auto-order.
#. Set the Success Extra Message shown after Buy, under the order number.
#. Add Spanish (Venezuela) in Website Languages if it is missing, then choose
   the Kiosk Language used on /auto-order.
#. Publish the products that should be found by the scanner.
#. Open /auto-order on a device with a camera and allow camera access.
