#. Install **Device Bridge** on the database that has the POS-80 (recommended).
#. Create the printer in Device Bridge **for the company that owns the
   warehouse**. The same physical USB printer does not print for another
   company unless that company has its own Device Bridge record assigned.
#. Open the report **POS-80 Delivery Ticket** (or the Device Bridge printer)
   and assign that printer in **Device Bridge printers** / **Reports**.
#. Keep a Chrome or Edge tab connected **on the PC with the USB cable** so
   the gateway stays online. Other PCs (cash register, salesperson) send the
   job to that gateway; they must not stay registered as extra gateways.
#. Inventory settings: enable or disable **Auto-print POS-80** per company.
