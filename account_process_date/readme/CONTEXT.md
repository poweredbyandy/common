The accounting date of a document is not always the day it was handled. Some
companies need to know when a payment or a journal entry was really processed,
for example to reconcile the daily cash and bank movements.

This field used to live in `l10n_ve_seniat`. It moved here because it is a
customer need, not a legal requirement. The technical name
`l10n_ve_process_date` is kept so existing data and customizations keep
working.
