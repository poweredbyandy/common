#. Vaya a **Ajustes > Fondo del menú** o a **Ajustes > Empresas** y abra
   la pestaña **Fondo del menú**.
#. Suba la imagen.
#. Elija el tamaño (100, 70, 50, 40, 20) o **Personalizado** para
   escribir otro porcentaje.
#. Elija la posición (centrado, abajo a la derecha, abajo a la izquierda,
   etc.).
#. Ajuste la opacidad (0 a 100).
#. Recargue la página del backend para ver el resultado.
