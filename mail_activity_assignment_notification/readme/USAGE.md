1. Abra un documento (un contacto, un pedido, una factura, etc.).
2. Planifique una actividad y asígnela a un usuario.
3. Ese usuario ve la actividad en Mis actividades.
4. En la campana aparece «Se te asignó: … en …» con el botón **Abrir**,
   que lleva al documento.
5. Si la actividad cambia de responsable, el nuevo usuario recibe el mismo
   aviso.
