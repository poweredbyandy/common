Sincronización automática
=========================

#. Instale el módulo.
#. Abra un contacto comercial.
#. Edite la lista de precios, los términos de pago o el límite de crédito en la compañía activa.
#. Cambie de compañía y verifique que los campos compatibles reflejan el mismo valor.

Sincronización manual
=====================

Desde un contacto:

#. Abra la pestaña Contabilidad.
#. Pulse **Sincronizar propiedades entre compañías**.
#. Seleccione la compañía origen, las compañías destino y, opcionalmente, los campos a copiar. Si no selecciona campos, se sincronizarán todos los detectados automáticamente.
#. Confirme con **Sincronizar**.

Desde la lista de contactos:

#. Seleccione uno o varios contactos.
#. Use la acción **Sincronizar propiedades entre compañías** del menú Acción.

Desde Contactos:

#. Vaya a **Contactos > Sincronizar propiedades de contactos** para ejecutar una sincronización masiva.
