1. Set the user's email to the Gmail / Workspace address they will use.
2. Click the envelope icon in the systray and choose **Connect Gmail**.
3. Complete the Google consent screen with that same account.
4. When the icon is green, outgoing mail uses that address.
5. When the icon is red and the user sends an email, Odoo asks whether to send
   as the company account or to connect Gmail first.
6. Administrators can review every account under
   **Settings > Users & Companies > Gmail Accounts**.
