Usage
=====

#. Instale el modulo ``pba_web_external_layout``.
#. Abra **Configurar diseno del documento** desde ajustes.
#. Seleccione el layout **Presupuesto PBA** para aplicar el estilo PBA.
#. En **Fondo**, seleccione **Personalizado** y cargue la imagen deseada.
#. Seleccione cualquier otro layout para mantener el diseno nativo de Odoo.
