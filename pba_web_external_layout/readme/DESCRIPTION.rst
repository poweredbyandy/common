PBA Web External Layout
=======================

Estilo visual PBA integrable con el configurador nativo de documentos de Odoo.
Reposiciona los bloques originales sin volver a declarar sus campos.
Admite los colores, fuentes, logotipo e imagen de fondo configurados en Odoo.
Aplica el mismo grid de información a ventas, facturas y transferencias de inventario.
