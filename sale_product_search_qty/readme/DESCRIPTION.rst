Este módulo muestra la cantidad a mano del producto en las líneas de búsqueda
del campo producto en los pedidos de venta.

Al escribir en el many2one de producto (variante o plantilla), cada opción del
desplegable muestra un badge con la cantidad a mano a la derecha del nombre.

La cantidad se calcula con el almacén del pedido y solo se muestra para
productos almacenables.
