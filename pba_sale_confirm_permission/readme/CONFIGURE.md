1. Instale el módulo. Los usuarios del grupo **Usuario: Ventas propias** reciben
   el permiso **Confirmar pedidos de venta**.
2. Para ocultar el botón a un usuario, abra **Ajustes > Usuarios** y quite el
   grupo **Confirmar pedidos de venta**.
3. Para volver a mostrarlo, asigne de nuevo ese grupo.
